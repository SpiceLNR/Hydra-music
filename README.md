# Hydra Music

Личный аудиоплеер с синхронизацией папок между вашими устройствами напрямую (P2P), без облака.
Интерфейс в стиле Metro (Windows Phone): плоские плитки, крупные светлые заголовки, зелёный акцент,
навигация кнопками, без панорамы и свайпов.

Статус: **этап 1 - каркас**. Работают экраны (на демо-данных), Rust-ядро с журналом операций,
часами и правилами имён. Сеть, реальный плеер и файловая система подключаются на следующих этапах.

## Структура

```
core/     Rust: гибридные часы, журнал операций, SQLite, правила имён, корзина
app/      Flutter: интерфейс (Android, затем Windows)
bridge/   связка Flutter <-> Rust (этап 2)
docs/     архитектура и протокол
tools/    вспомогательные скрипты
```
