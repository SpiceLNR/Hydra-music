# Hydra Music

Личный аудиоплеер с синхронизацией папок между вашими устройствами напрямую (P2P), без облака.
Интерфейс в стиле Metro (Windows Phone): плоские плитки, крупные светлые заголовки, зелёный акцент,
навигация кнопками, без панорамы и свайпов.

Статус: **этап 1 - каркас**. Работают экраны (на демо-данных), Rust-ядро с журналом операций,
часами и правилами имён. Сеть, реальный плеер и файловая система подключаются на следующих этапах.

## Структура

```
core/     Rust: гибридные часы, журнал операций, SQLite, правила имён, корзина
app/      Flutter: интерфейс (Android, затем Windows)
bridge/   связка Flutter <-> Rust (этап 2)
docs/     архитектура и протокол
tools/    вспомогательные скрипты
```

## Как запустить

### Вариант А: готовый APK из облака (ничего ставить не нужно)

1. Создайте репозиторий на GitHub и загрузите туда папку проекта.
2. Откройте вкладку **Actions**: запустятся два задания.
   - `Rust core tests` прогоняет тесты ядра.
   - `Android debug APK` собирает приложение.
3. Скачайте файл `hydra-music-debug-apk` со страницы завершённого запуска, распакуйте и установите
   `app-debug.apk` на телефон (разрешите установку из неизвестных источников).

### Вариант Б: сборка на своём компьютере

1. Установите [Flutter](https://docs.flutter.dev/get-started/install) и [Rust](https://rustup.rs).
2. Тесты ядра:
   ```
   cd core
   cargo test
   ```
3. Приложение:
   ```
   cd app
   flutter create --platforms=android,windows --project-name hydra_music --org dev.hydra .
   python3 ../tools/patch_android_manifest.py
   flutter pub get
   flutter run
   ```
   Телефон подключите по USB с включённой отладкой.

> `flutter create .` дописывает платформенные папки (`android/`, `windows/`) и не трогает `lib/`.

## Разрешения на Android

Скрипт `tools/patch_android_manifest.py` добавляет их сам. Главное из них - «Доступ ко всем файлам»
(`MANAGE_EXTERNAL_STORAGE`): после первого запуска его нужно один раз включить вручную в
*Настройки → Приложения → Hydra Music → Разрешения → Файлы*. Также стоит исключить приложение из
экономии батареи, иначе Android будет усыплять синхронизацию.

## Шрифт

Для настоящего Metro-вида положите шрифт Selawik (MIT) в `app/assets/fonts/` и раскомментируйте
блок `fonts:` в `app/pubspec.yaml`. Без него используется системный шрифт.
