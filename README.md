# Hydra Music

Личный аудиоплеер для Android и Windows с синхронизацией музыки между вашими устройствами
напрямую, без облака и аккаунтов. Интерфейс в стиле Metro (Windows Phone): плоские плитки,
крупные светлые заголовки, зелёный акцент, только кнопки и списки, без скруглений,
без панорамы и свайпов.

Проект с открытым исходным кодом. Ядро написано на Rust, интерфейс на Flutter.

## Идея в двух словах

- **Плейлист — это обычная папка.** Музыка лежит в `Music/Hydra/<Плейлист>` и видна в любом
  проводнике и плеере. Приложение не прячет файлы в свою базу.
- **Нет облака.** Устройства обмениваются музыкой друг с другом напрямую.
- **Ничего не теряется.** Удаление отправляет трек в корзину на 30 дней. Конфликты правок
  решаются по времени, одинаково на всех устройствах.

## Библиотека: папки и плейлисты

- Корневая папка библиотеки:
  - Android: `Music/Hydra`;
  - Windows: `Музыка\Hydra` (`%USERPROFILE%\Music\Hydra`).
- Каждая вложенная папка — плейлист. Порядок треков хранится в скрытом файле
  `.<Плейлист>.json`; в нём треки записаны по постоянному идентификатору (UUID),
  а не по имени файла.
- Каждый трек получает UUID при первом добавлении. Переименование файла в проводнике
  не делает его «новым» треком.
- При запуске приложение сканирует папку и подхватывает всё, что вы добавили вручную.
- Названия папок и файлов очищаются от запрещённых символов и зарезервированных имён Windows,
  чтобы одни и те же файлы одинаково открывались на обоих системах.
- Форматы: mp3, flac, wav, ogg, oga, opus, m4a, aac, wma, aiff, aif, ape, wv, mka, m4b.
  Видеоконтейнеры (mp4, mkv, webm, avi, mov, m4v) тоже читаются: играет звук.

**Действия с плейлистами:** создать, переименовать, удалить, переставить порядок плейлистов.

**Правило сортировки плейлиста** (выбирается для каждого плейлиста отдельно):

| Правило | Что делает |
|---|---|
| По исполнителю | треки сразу упорядочиваются по исполнителю, новые встают на своё место сами |
| По названию трека | то же по названию |
| Как попало | порядок задаёте вы: перетаскиванием |

Ручная перестановка переключает правило в «Как попало».

## Работа с треками

- **Добавление:** положите файл в папку плейлиста, при следующем скане он появится.
  Название, исполнитель и обложка читаются из тегов файла.
- **Переименование, исполнитель, обложка:** в окне плеера есть шестерёнка. Окно «Настройки трека»
  содержит «Изменить обложку», поле названия и поле исполнителя. Изменения записываются в теги
  файла. Если формат не хранит теги, правка сохраняется только в приложении, и приложение об этом скажет.
  Пустой исполнитель очищает поле.
  На Windows название и обложка меняются через меню трека в списке.
- **Перемещение** трека между плейлистами: переносит физический файл.
- **Перестановка** треков внутри плейлиста перетаскиванием.
- **Удаление:** трек уходит в корзину (с подтверждением).
- **Бегущая строка:** длинные названия в списках и плеере плавно прокручиваются.

## Плеер и режимы воспроизведения

Элементы плеера: обложка, название и исполнитель, полоса позиции, «назад», «пауза/играть»,
«вперёд», громкость (на Windows вертикальная полоса у края окна).

- **«Назад»:** первое нажатие возвращает в начало трека, второе подряд (в течение 1,5 с) —
  к предыдущему треку.
- **Очередь идёт по кругу:** после последнего трека играет первый, «вперёд» на последнем тоже
  ведёт к первому.

**Режимы воспроизведения** — широкий переключатель-ползунок со значками, слева направо:

| Значок | Режим | Что делает |
|---|---|---|
| повтор одного | **Повтор** | текущий трек играет по кругу |
| список | **Стандартный** | плейлист по порядку и по кругу |
| перемешивание | **Разнобой** | случайный порядок текущего плейлиста, при каждом включении новый |
| пламя | **Анархия** | случайный порядок всех плейлистов вместе (корзина не входит) |

- Режим выбирается нажатием на значок. Квадрат-ползунок плавно переезжает на выбранный режим.
- Переключение режима не прерывает трек: он продолжается с того же места. Возможна короткая заминка.
- При выходе из «Разнобоя» и «Анархии» дальше играет плейлист, которому принадлежит
  текущий трек.
- В режиме «Анархия» все зелёные элементы плеера (кнопка паузы, переключатель, полосы позиции
  и громкости) становятся красными. Остальное приложение не меняется.
- При запуске приложения всегда включён «Стандартный».

## Защита от случайного массового удаления

Если вне приложения (например, в проводнике) пропала папка плейлиста или большая часть его
файлов (5 и более), приложение **ничего не удаляет и не отправляет на другие устройства**.
Вместо этого вверху появляется вопрос с двумя ответами:

- **Вернуть с других устройств** — треки остаются, а недостающие файлы скачиваются при
  ближайшей синхронизации;
- **Удалить везде** — после подтверждения треки уходят в корзину на всех устройствах.

Одиночные удаления файлов (меньше 5) применяются сразу, как раньше.

## Корзина

- Удалённые в приложении треки лежат в корзине 30 дней, потом стираются сами.
- Из корзины можно восстановить трек или удалить его навсегда, а также очистить её целиком.
- Более поздняя правка или перемещение трека на другом устройстве возвращает его из корзины.
- Удаления, пришедшие по синхронизации, тоже идут в корзину, но повторно не спрашиваются.
- В корзине показываются только треки, у которых на устройстве есть файл. Удаления, о которых
  устройство узнало по журналу, но чьих файлов у него никогда не было, в корзину не попадают.
- После переустановки или сброса базы приложение подхватывает из скрытой папки `.trash` только
  то, что удалено не более 30 дней назад: более старое корзина всё равно стёрла бы.

## Синхронизация устройств

Синхронизация работает **по локальной сети (Wi-Fi)** и **через интернет** (библиотека iroh):
устройства находят друг друга по ключу и соединяются напрямую или, если не получается,
через промежуточный сервер (relay). Музыка и журнал шифруются на устройствах, сервер видит
только зашифрованный поток. Через интернет синхронизируются устройства, которые уже
сопряжены; для первого сопряжения устройства должны видеть друг друга в одной сети или
иметь доступ к интернету. В настройках интернет можно выключить, а на Android ограничить
неплатной сетью (Wi-Fi).

**Как это устроено**
- Между устройствами передаются операции журнала (добавление, перемещение, правка, удаление,
  перестановка), а затем недостающие файлы. Каждый файл проверяется по SHA-256.
- Журнал использует гибридные логические часы: итог не зависит от порядка доставки,
  а расхождение часов на устройствах не ломает порядок событий.
- Одновременная работа на двух устройствах сходится к одному результату.
- Одновременно идёт только один сеанс синхронизации.
- Порты: TCP 47475 (обмен), UDP 47476 (поиск устройств в сети).

**Сопряжение (один раз)**
1. На одном устройстве откройте «Устройства» и покажите QR-код сопряжения.
   Он одноразовый и действует 3 минуты.
2. На втором откройте сканер QR и наведите на код.
   Запасные способы: открыть ссылку `hydra://pair?…` обычной камерой телефона или вставить
   её вручную («Ввести ссылку вручную»).
3. Устройства запоминают друг друга и сразу синхронизируются.

**Автосинхронизация** (включена по умолчанию, отключается в «Настройках»): устройства из вашей
семьи сами синхронизируются, как только оказываются в одной сети, и затем примерно раз в
10 минут. На Android для этого висит уведомление «Автосинхронизация включена»: служба держит
приложение живым и принимает подключения, не расходуя процессор. Есть настройка «Только во время
зарядки» и кнопка «Разрешить работу в фоне» (исключение из экономии батареи). На Windows
автосинхронизация работает, пока приложение запущено.

**Дальше** устройство видно в списке, где можно запустить синхронизацию вручную или
забыть устройство. Если забыть устройство во время синхронизации, идущий сеанс обрывается.

**Журнал.** Кнопка в правом верхнем углу экрана «Устройства» открывает отдельный экран с журналом
сети: у каждой записи есть дата и время. По нему видно, как прошло сопряжение и синхронизация,
сколько операций и файлов обменяно, сколько треков ушло в корзину и почему. Хранятся последние
100 записей.

**Условия для сети Wi-Fi:** оба устройства в одной сети (через интернет это не нужно). Гостевые сети и «изоляция клиентов» на роутере
мешают. На Windows может понадобиться разрешить Hydra Music в брандмауэре.

## Android

- Фоновое воспроизведение: служба переднего плана, уведомление с кнопками, управление с экрана
  блокировки и из наушников.
- Звук играет системный ExoPlayer: экономно по батарее и без заиканий.
- Во время синхронизации включается отдельная служба (с уведомлением), которая не даёт
  Android усыпить приложение при выключенном экране.
- Нужен доступ ко всем файлам, чтобы работать с папкой `Music/Hydra`.
- Сканер QR работает без сервисов Google (проверено на GrapheneOS).
- Если нет доступа к папке или библиотека ещё открывается, плитки «Плейлисты», «Устройства»
  и «Корзина» на главном экране недоступны.
- Минимальная версия: Android 11.

## Windows

Окно приложения — «шторка» у края экрана:

- узкое окно на всю высоту рабочей области (до панели задач), прижато к выбранному краю;
- при клике вне окна сворачивается в зелёную кнопку 40×40 со стрелкой у того же края
  по центру высоты и остаётся поверх других окон; клик по кнопке разворачивает окно;
- в панели задач приложения нет, рамки Windows тоже нет;
- ширина окна меняется перетаскиванием края (от 320 до 700 пикселей);
- вертикальная полоса громкости со стороны закрепления;
- открытые «Устройства» и «Настройки» сохраняются при сворачивании окна.

Музыка берётся из `Музыка\Hydra`. Приложение не подписано, поэтому SmartScreen может
предупредить: нажмите «Подробнее» → «Выполнить в любом случае».

## Настройки

- **Окно (Windows):** сторона закрепления (слева/справа), сворачивание в полоску при клике вне окна.
- **Автосинхронизация:** включение и выключение, «только во время зарядки» и разрешение работы в фоне (Android).
- **Папка библиотеки:** показывает, откуда читается музыка.
- **Ядро синхронизации:** статус Rust-ядра.
- **Версия:** номер версии и идентификатор сборки (первые символы коммита). Если сборка не
  совпадает с последним коммитом, значит, установлена старая версия.
- **Интернет:** включение связи через интернет (iroh) и ограничение «только по Wi-Fi» (Android).

## Безопасность и приватность

- Музыка и журнал не покидают ваши устройства, облака нет.
- Соединение между устройствами шифруется (Noise, TCP). Сопряжение требует одноразовый
  секрет из QR-кода; принимаются соединения только от сопряжённых устройств.
- Приложение не собирает статистику.

## Сборка и установка

Сборка выполняется в GitHub Actions (файл `.github/workflows/ci.yml`):

- `core-tests` — проверка и тесты ядра на Rust;
- `android-apk` — анализ, тесты и сборка release-APK;
- `windows-build` — сборка папки Windows.

Готовые сборки публикуются в Releases под тегом `latest`. Android-сборка подписывается
постоянным ключом из секрета репозитория `HYDRA_KEYSTORE_B64` (в самом репозитории ключа нет),
поэтому новая версия ставится поверх старой. В своём форке создайте свой ключ и секрет
с тем же именем; без секрета сборка получит временный ключ.

**Android:** скачайте `.apk` и установите (разрешите установку из неизвестных источников).

**Windows:** скачайте архив, распакуйте в любое место и запустите `hydra_music.exe`.
Рядом должен лежать `hydra_ffi.dll` (он уже в архиве).

Локальная сборка: нужны Rust, Flutter и (для Android) Android SDK. Перед сборкой Android
выполните `python tools/patch_android_manifest.py`: он добавляет в проект разрешения, службы
и ссылки `hydra://pair`. Для Windows тот же скрипт убирает показ окна до первого кадра.

## Структура репозитория

```
core/     Rust: часы, журнал операций, SQLite, имена, порядок, теги, корзина, сеть и синхронизация
ffi/      C-интерфейс ядра для Flutter (hydra_call: JSON -> JSON)
app/      Flutter: интерфейс Android и Windows
bridge/   вспомогательные файлы связки Flutter <-> Rust
docs/     архитектура и протокол (ARCHITECTURE.md)
tools/    скрипты (настройка Android и Windows-проекта, ключ подписи)
```

Подробности устройства журнала, порядка треков и протокола: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
